❓ ENTONCES, ¿PARA QUÉ SIRVE EL BOTÓN “Manual Deploy”?

Ese botón sirve solo en casos especiales:

🟡 Cuándo usar Manual Deploy

Cambiaste variables de entorno (SECRET_KEY, DB, etc.)

El último deploy falló y querés reintentar

Render quedó “colgado”

Querés redeployar sin cambiar código

🔴 Cuándo NO hace falta

Cambios de código

Cambios de templates

Cambios de CSS

Cambios de URLs

👉 En todos esos casos, git push alcanza.
